# 安裝喵叔 Moonlit Stories 到桌面／主畫面

網站：https://vetjeremy-jpg.github.io/miaoshu.github.io/

## Windows（Microsoft Edge / Google Chrome）
1. 開啟上述網站。
2. Edge：選擇「…」→「應用程式」→「將此網站安裝為應用程式」（選項名稱可能依版本略有不同）。Chrome：選擇網址列安裝圖示，或「…」選單中的安裝頁面選項。
3. 確認安裝名稱與金色貓圖示；可釘選至工作列或開始功能表。
4. 從已安裝 APP 圖示啟動，應以獨立視窗顯示，不出現一般瀏覽器分頁／網址列。

## Android（Chrome）
1. 開啟網站。
2. 選擇「⋮」→「安裝應用程式」；部分裝置顯示「新增至主畫面」。
3. 從主畫面金色貓圖示啟動。

## iPhone（Safari）
1. **使用 Safari** 開啟網站。
2. 點選分享圖示 →「加入主畫面」。
3. 若系統顯示「以網頁 App 開啟」，請開啟該選項，再加入。
4. 從主畫面圖示啟動。

## 驗收注意
- iOS 不保證提供與 Android 相同的自動安裝提示；Safari 的分享選單是主要入口。
- 不同系統版本、瀏覽器與網站開啟方式可能影響安裝選單文字與獨立視窗行為。
- 只保證已造訪、成功快取的頁面可在離線時作為候補；外部相簿、影片與未預載內容仍需要網路。
- 若圖示或內容沒有更新，先在連線狀態下重新開啟 APP；不要直接清除網站資料，以免遺失保存在本機的閱讀進度。
